# Estudos

App de estudos com cronômetro, plano por disciplina, revisões espaçadas (1, 3, 7, 15 e 30 dias), gráficos de desempenho, exercícios gerados por IA, atividade física e agenda.

## Tecnologias
HTML, CSS e JavaScript puro, Electron (Windows) e Capacitor (Android).

## Como rodar
npm install
npm start

## Gerar instalador
npm run build
